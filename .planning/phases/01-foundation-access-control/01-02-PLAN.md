<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tauri IPC (React → Rust) | Untrusted LoginDto/CreateUserDto payloads from UI |
| Rust in-memory (session HashMap) | Session tokens stored in process memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Spoofing | `auth_commands::auth_login` | mitigate | bcrypt::verify() with constant-time comparison via bcrypt crate; error messages do not distinguish "user not found" from "wrong password" (generic "Invalid credentials") |
| T-01-07 | Elevation of Privilege | `user_commands::create_user` | mitigate | `require_owner()` guard on every user_commands call; pharmacist session token rejected with FORBIDDEN |
| T-01-08 | Elevation of Privilege | `audit_commands::get_login_attempts` | mitigate | `require_owner()` guard; pharmacist cannot view audit log per D-09 |
| T-01-09 | Tampering | SQL injection via IPC | mitigate | All rusqlite queries use `?` prepared statement placeholders — never string concatenation of user input |
| T-01-10 | Repudiation | Login audit logging | mitigate | Every login attempt (success and failure) logged with timestamp, username, success/failure, role before response returns to caller |
| T-01-11 | Information Disclosure | Session token in IPC responses | accept | Session token sent to React frontend per D-04 (it needs it for subsequent commands). Token is UUID v4 (unguessable). NOT stored in localStorage — held in React component state only. |
| T-01-12 | Elevation of Privilege | Setup wizard | mitigate | `create_initial_owner` checks `SELECT COUNT(*) FROM users` and rejects if any user exists. Cannot be used to overwrite existing accounts. |
</threat_model>
