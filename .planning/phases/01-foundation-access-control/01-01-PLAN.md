<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tauri IPC (React → Rust) | Untrusted UI input crosses to backend command handlers |
| File system (app data dir) | SQLite database file on disk accessible to OS-local processes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `guards.rs` — session token validation | mitigate | `require_session()` checks session exists in Mutex<HashMap> before any command proceeds; token not in HashMap = reject |
| T-01-02 | Information Disclosure | SQLite DB file on disk | accept | No encryption-at-rest for v1. File protected by OS-level app data directory permissions. Reevaluate if PHI sensitivity increases in v2. |
| T-01-03 | Elevation of Privilege | `require_owner()` guard | mitigate | Every privileged command calls `require_owner()` on every invocation — not just hiding buttons in UI. Returns FORBIDDEN error if pharmacist attempts owner command. |
| T-01-04 | Denial of Service | Mutex lock contention (db + sessions) | mitigate | Consistent lock ordering enforced (db first, sessions second) per Pitfall 3. Short lock durations — release before returning. |
| T-01-05 | Tampering | Migration SQL injection | mitigate | All migration SQL is embedded at compile time via `include_str!`. No runtime string concatenation in DDL. |
</threat_model>
