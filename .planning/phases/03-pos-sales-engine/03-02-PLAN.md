## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Tampering | POSPage cart state — inflated totals displayed to user | accept | Display-only estimates; server recalculates all values at confirm (D-35); frontend cannot tamper with final total |
| T-03-08 | Tampering | confirm_sale payload — item_discount/bill_discount manipulation | mitigate | Server validates discounts against role permissions (D-38) and caps at 100% (D-37); manipulated discounts rejected by service layer |
| T-03-09 | Spoofing | Credit sale without customer name | mitigate | Frontend requires customer_name when payment_method='Credit'; backend also validates (T-03-05) |
| T-03-10 | Information Disclosure | Purchase price visible in POS search | accept | MedicinePosDto explicitly excludes purchase_price field — no risk |
</threat_model>
