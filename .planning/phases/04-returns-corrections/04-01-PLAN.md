    ### `process_customer_return(db, payload, user_id) -> Result<ReturnReceiptDto, CommandError>`

    **Phase 1 — Validate before transaction:**
    1. Load sale via `sale_repo::find_by_id(db, payload.sale_id)` — error if not found.
    2. Load sale items via `sale_repo::find_items_by_sale(db, payload.sale_id)`.
    3. For each returned item in `payload.items`:
       a. Validate D-46: find matching `sale_item` by sale_item_id (must exist).
       b. Compute `already_returned_qty`: SUM of qty from `returns_repo::find_by_sale_item(db, sale_id, medicine_id, batch_id)` where return_type='customer'.
       c. Validate `item.quantity <= sale_item.quantity - already_returned_qty` — if exceeded, return VALIDATION error.
       d. Validate condition is one of "resellable", "damaged", "expired" (D-45).
       e. Validate refund_amount >= 0.

    **Phase 2 — Open transaction:**
    4. `let tx = db.transaction()?`

    **Phase 3 — Insert returns + mutate stock:**
    5. For each validated item:
       a. `returns_repo::insert(&tx, "customer", Some(sale_id), medicine_id, Some(batch_id), quantity, reason, Some(condition), refund_amount, user_id)`
       b. If condition == "resellable":
          - `batch_repo::increment_remaining_qty(&tx, batch_id, quantity)` — restore stock per D-45
          - `stock_ledger_service::record_movement(&tx, "customer_return", medicine_id, Some(batch_id), quantity, "sale", Some(sale_id), Some("Resellable customer return"), user_id)` — positive delta
       c. If condition == "damaged" or "expired":
          - `stock_ledger_service::record_movement(&tx, "write_off", medicine_id, Some(batch_id), 0, "sale", Some(sale_id), Some(&format!("{} customer return", condition)), user_id)` — quantity_delta=0 because batch was already deducted at sale time; this log serves as loss record for P&L (D-54).

    **Phase 4 — Commit:**
    6. `tx.commit()?`
    7. Return `ReturnReceiptDto` with the inserted return IDs, item count, and total refund.

    ### `process_supplier_return(db, payload, user_id) -> Result<ReturnReceiptDto, CommandError>`

    **Phase 1 — Validate:**
    1. Load purchase via `purchase_repo::find_by_id(db, payload.purchase_id)`.
    2. Load purchase items.
    3. For each item in `payload.items`:
       a. Load batch via repo — must exist and belong to this purchase.
       b. Validate `item.quantity <= batch.remaining_qty` (D-51: only unsold qty can be returned).
       c. Validate credit_amount >= 0.

    **Phase 2 — Transaction:**
    4. `let tx = db.transaction()?`

    **Phase 3 — Mutate:**
    5. For each item:
       a. `returns_repo::insert(&tx, "supplier", Some(purchase_id), medicine_id, Some(batch_id), quantity, reason, None, credit_amount, user_id)` — condition=NULL for supplier returns (D-52).
       b. `batch_repo::decrement_remaining_qty(&tx, batch_id, quantity)` — remove returned stock (D-50).
       c. `stock_ledger_service::record_movement(&tx, "supplier_return", medicine_id, Some(batch_id), -(quantity), "purchase", Some(purchase_id), Some("Supplier return"), user_id)` — negative delta (stock decrease).

    **Phase 4 — Commit:**
    6. `tx.commit()?`
    7. Return receipt.

    ### `process_write_off(db, payload, user_id) -> Result<ReturnReceiptDto, CommandError>`

    **Phase 1 — Validate:**
    1. For each item:
       a. Load batch — must exist.
       b. Validate `item.quantity <= batch.remaining_qty`.
       c. Validate condition is "expired" or "damaged".

    **Phase 2 — Transaction:**
    2. `let tx = db.transaction()?`

    **Phase 3 — Mutate:**
    3. For each item:
       a. `returns_repo::insert(&tx, "write_off", None, medicine_id, Some(batch_id), quantity, reason, Some(condition), 0.0, user_id)` — reference_id=NULL, refund_amount=0 (D-53).
       b. `batch_repo::decrement_remaining_qty(&tx, batch_id, quantity)` — deduct from inventory (D-54).
       c. `stock_ledger_service::record_movement(&tx, "write_off", medicine_id, Some(batch_id), -(quantity), "write_off", None, Some(&format!("Write-off: {}", condition)), user_id)` — negative delta, loss logged as stock_movement (D-54).

    **Phase 4 — Commit:**
    4. `tx.commit()?`
    5. Return receipt.
