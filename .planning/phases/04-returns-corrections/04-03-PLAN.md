    ### Create `src/components/returns/CustomerReturnForm.tsx`

    A form component following the PurchaseForm.tsx pattern. Props: `sessionToken`, `currencySymbol`, `onReturnComplete`.

    **State:**
    - `saleId` (string) — sale search input
    - `sale` (SaleForReturnDto | null) — loaded sale data
    - `loadingSale` (boolean)
    - `returnItems` (Record of `{\`${medicineId}-${batchId}\`: { sale_item_id, medicine_id, batch_id, quantity: string, condition, reason, refund_amount }}`) — items selected for return
    - `submitting` (boolean)
    - `success` (ReturnReceiptDto | null)
    - `error` (string | null)

    **Flow:**

    1. **Sale Search Section**: Input field for Sale ID with a "Search" button. On submit, call `tauri.returns.searchSaleForReturn(sessionToken, parseInt(saleId))`. If successful, display sale header info (date, payment method, total, customer name).

    2. **Items Table**: Display `sale.items` in a shadcn Table. Each row shows:
       - Medicine name, quantity sold, already returned qty, returnable qty, unit price
       - Return quantity input (number, max = returnable_qty per D-46) — frontend-enforce max
       - Condition Select: options "Resellable", "Damaged", "Expired" (per D-45)
       - Reason text input
       - Refund amount input (number, default = unit_price * qty but can differ per D-47)

       **How item state works:** When user types return qty > 0 for a row, it gets tracked in `returnItems`. When return qty is 0 or empty, the item is not included in the submit payload. Each row's check state is derived from whether returnItems has an entry for that item's key.

    3. **Summary Section**: Show total refund amount, item count.

    4. **Submit**: On submit, build `CustomerReturnDto` payload from `returnItems` and call `tauri.returns.processCustomerReturn(sessionToken, payload)`. On success, show green success banner with return IDs and total refund.

    **Validation (frontend courtesy — real enforcement is in Rust):**
    - Return qty cannot exceed `returnable_qty` per row
    - At least one item must have qty > 0
    - Refund amount must be >= 0

    **Layout:** Use `<Card>` with `<CardHeader><CardTitle>Customer Return</CardTitle></CardHeader>` and `<CardContent>` with form sections separated by spacing.
