Getting Started

When you launch PharmaCare for the first time, no accounts exist yet. The Setup Wizard guides you through creating the initial Owner account.

Setup Wizard

👤

Step 1 — Fill Details

Enter Full Name, Username (must be unique), and Password (minimum 6 characters).

✉️

Step 2 — Optional Email

Provide an email address for password recovery via OTP (requires SMTP configuration).

🔐

Step 3 — Auto-Login

After creating the Owner, PharmaCare automatically logs you in. No additional setup needed.

✅

Done — You're Ready

The wizard only appears once. From the next launch onward, you'll see the Login screen.

Login

Enter your Username and Password, then click Login (or press Enter).

Security NotePharmaCare shows a generic "Invalid credentials" message whether the username is wrong or the password is wrong — this prevents attackers from guessing valid usernames.
TipAll login attempts (successful and failed) are recorded in the Audit Log, visible to the Owner.

Password Recovery (Forgot Password)

If you forget your password, click Forgot Password? on the login screen. A 6-digit OTP code is sent to the configured owner email address. Enter the code to verify your identity, then set a new password.

Requires SetupPassword recovery only works if SMTP credentials are configured in environment variables (contact your system administrator) and the owner email is set in Settings.

5

Medicine Catalog

The Medicine Catalog stores all your medicine master data. Both roles can view, but only Owners can create, edit, or delete medicines.

💊

Creating a Medicine

Required fields: Name, Category (Tablet/Syrup/Injection/OTC/Prescription), Unit (Strip/Bottle/Vial/Box/Sachet), Retail Price (must be ≥ Purchase Price), and Purchase Price.

📦

Opening Stock

When creating a medicine, you can set an Initial Quantity and Expiry Date. This creates an opening-stock batch automatically (code: OPEN-{id}).

✏️

Editing & Deactivating

You can edit any medicine's fields. Deactivate soft-disables a medicine (it won't appear in searches). Delete is only available for medicines with no batches.

👁️

Pharmacist View

Pharmacists see a restricted view that hides the Purchase Price column — cost data stays confidential.

6

Suppliers

Manage your supplier list. Owners can create, edit, deactivate, and delete suppliers. Pharmacists can view the supplier list.

NoteSuppliers with purchase records cannot be hard-deleted. Use Deactivate instead.
7

Purchases

Record stock received from suppliers. Each purchase creates one or more inventory batches with auto-generated batch codes (B-{item_id}). Owner only.

📋

Recording a Purchase

Select a Supplier, enter Invoice Number and Purchase Date, set Payment Status (Paid/Pending/Partial). Add line items with medicine, quantity, expiry date, and unit price.

🔗

Atomic Transaction

Everything is wrapped in a single transaction. If any item fails (e.g. invalid medicine), nothing is saved. No partial purchases.

🔄

Customer Return

Both roles. Look up sale by ID. Resellable items restore stock; damaged/expired items log as loss. Cannot return more than was sold.

⬆️

Supplier Return

Owner only. Look up purchase by ID. Stock is deducted from the batch. Records a credit amount.

🗑️

Write-Off

Owner only. Directly dispose of expired or damaged stock from a batch. Not linked to any sale or purchase.

10

Debts

Track customer credit separately from POS payments. Owner only.

➕

Creating a Debt

Enter Customer Name, add items with medicine name, quantity, and amount. Set a Due Date. Total is auto-calculated.

💵

Recording Payment

Enter the payment amount — cannot exceed the remaining balance. Status updates automatically: fully paid → paid, past due date → overdue.

Expiry Report — Status Colors

The Expiry Report color-codes each batch based on its remaining days before expiry:

OK

More than Warning Days (default: 60) remaining. No immediate action needed.

Warning

Within the Warning window between critical and warning days. Consider markdowns or returns.

Critical / Expired

Within Critical Days (default: 30) — act fast. Expired stock shows in dark red. Potential loss is calculated automatically.

Configure ThresholdsBoth warning and critical day thresholds are adjustable in Settings → Inventory.

⏰

Automatic Backup

Set a time in Settings (default 23:00). PharmaCare checks every 60 seconds and backs up when the time matches. The app must be running.

☁️

Google Drive

Connect your Google Drive via OAuth. Backups are uploaded to a PharmaCareBackups folder. Requires a Google Drive Client ID and Secret.

🔄

Restore

Restore from local backup or Google Drive. A pre-restore backup is always created before restoring, so you can undo if needed.

🗃️

Backup Rotation

Maximum 30 backups are kept. The oldest backup is automatically removed when a new one exceeds the limit.

Audit Log

View the last 100 login attempts. This helps you monitor unauthorized access attempts. Owner only.

🕐

What's Logged

Timestamp, username attempted, whether it succeeded or failed, and the failure reason (wrong password, inactive account, etc.).

🔒

Why It Matters

If someone is repeatedly trying to log in with wrong credentials, you'll see it here. Take appropriate action if needed.

Troubleshooting

Application won't start

1. Make sure no other instance of PharmaCare is already running.
2. Check the terminal or console for error messages.
3. If the database is corrupted, restore from the most recent backup.
4. As a last resort, delete the database file (check Settings for the location) — you will lose all data not backed up.

"An error occurred" on a page

This means the backend returned an error that couldn't be displayed as a readable message. Check the developer console (Ctrl+Shift+I → Console tab) for details. Common causes include database constraint violations or missing data.

Google Drive backup failing

1. Verify your Client ID and Client Secret are correct.
2. Make sure you completed the OAuth authorization in your browser.
3. Check your internet connection.
4. Try disconnecting and reconnecting Drive in Settings.

Email OTP not sending

1. SMTP credentials must be configured via environment variables (contact your system administrator).
2. The owner email must be set in Settings → Financial → Owner Email.
3. Verify the SMTP server is reachable from your network.

Stock showing incorrect values

All stock mutations go through the Stock Ledger Service, which maintains an append-only log. If you suspect data corruption:
1. Navigate away and come back to refresh.
2. Restart the application.
3. If the problem persists, restore from a backup.

Can I undo a sale, purchase, or return?

PharmaCare does not have an "undo" feature. Sales, purchases, and returns are permanent once processed. For incorrect sales, you can process a Customer Return. For incorrect purchases or write-offs, restore from a backup taken before the error.

I forgot my password and didn't set up email

If the email OTP system wasn't configured, the only recovery option is to contact your system administrator. They can reset the database or create a direct SQL update to reset the password hash. This is a last-resort operation.

How do I know when backups run?

The Backup tab in Settings shows the Last Backup Time and Status. If auto-backup is configured at 23:00, you'll see the result there the next morning. For manual backups, the result is shown immediately after clicking "Backup Now".
